# Security policy

## Supported versions

Only the latest stable Happen release is supported with security updates.

## Report a vulnerability

Report suspected vulnerabilities privately through the
[Happen security advisory form](https://github.com/tab0inc/happen-releases/security/advisories/new).
Do not open a public issue for a security vulnerability.

Include the affected version, macOS version, reproduction steps, and impact.
Do not include access tokens, credentials, private messages, or other user
data. Tab0 Inc. will acknowledge the report and coordinate disclosure after a
fix is available.
